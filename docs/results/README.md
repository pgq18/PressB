# 发布的实验结果摘要

这些文件汇总已完成的本地评估和功能验收记录，不需要下载模型或运行 Isaac 即可查看。

- [Ascend 910C π₀.₅ 接入验证（2026-11-13）](pi05_ascend_20261113.json)：真实基础权重的单卡训练／推理，以及六卡训练、验证、检查点导出通过；包含输入版本与校验摘要，不代表完整训练已完成或仿真成功率。
- [Stack／Cleanup 评估提速（2026-11-13）](evaluation_performance_20261113.json)：同一模型／任务配置下的 512-transition 性能探针，两个任务吞吐约提升 1.65／2.00 倍；不同 worker 随机流，不作为配对成功率结果。
- [紧凑轨迹](compact_manipulation_20261112.json)与[工作区居中初始位姿](centered_manipulation_20261112.json)：规划与物理验证摘要；末尾撤离代替回初始位姿，稳定性检查帧不进入监督数据。
- [Playground 外观匹配（2026-11-13）](playground_appearance_20261113.json)：颜色、材质和光照调整，含选用配置与验证范围。

- [DPPO reset 优化后与 DSRL 的速度／资源对照（2026-11-09）](dppo_batched_reset_vs_dsrl_20261109/README.md)：三组 64 环境 DPPO 重新实测，与历史同配置 DSRL 比较；DP／VLA-JEPA／Wall-OSS 吞吐为 21.73／6.18／1.93 transitions/s，较旧 DPPO 提高 26.6%／4.9%／11.9%。包含完整训练耗时、分项耗时、显存、利用率、功率与 CPU／内存记录；DSRL 本次未重跑，不作为收敛速度比较。

- [DPPO 批量 reset 优化（2026-11-09）](dppo_reset_optimization_20261109/README.md)：64 环境真实 Isaac 对照，一次重置 8／32／64 个环境的服务耗时分别减少至原来的约 1/7.70、1/28.08、1/49.94；逐环境 seed 与物理状态保持，598 项回归通过。该结果仅测 reset 环节，不代表整场训练提速。

- [DSRL 与 DPPO 的 64 环境速度对照（2026-11-08／09）](dsrl_vs_dppo_64env_20261108/README.md)：三组新的 DSRL 实际训练，与上轮 DPPO 按各模型相同交互预算、外部配置和 GPU 部署比较；包含完整训练循环、匹配区间吞吐、异步重叠耗时与硬件资源。两种方法保留各自调度和解码实现，不作为达到目标成功率所需时间的比较。

- [DPPO 64 环境速度与资源测试（2026-11-08）](dppo_64env_benchmark_20261108/README.md)：Diffusion Policy、VLA-JEPA、Wall-OSS 均完成真实参数更新及推理端权重同步；包含分项耗时图、调用次数与延迟、GPU／CPU／内存记录。三者去掉前两轮后的吞吐分别为 17.554、5.897、1.740 transitions/s；任务、动作块长度和硬件配置不同，且本次跳过检查点写盘，不作为严格的跨模型或 DSRL 对照。

- [Diffusion Policy／DPPO 集成实测（2026-11-08）](../dppo_validation.md)：包含监督训练、三个模型的真实 action expert 更新与配对评测。保守 DP 13%→16%、原生 K4 VLA 33%→39%，尚不能确认稳定提升；Wall 63%→8%，明显退化。每轮前后各 100 条，早期负结果也保留；附[便携数据](dppo_integration_20261108/summary.json)与[对比图](dppo_integration_20261108/paired_success.png)。

- [组件归属重构验收（2026-11-07）](component_ownership_20261107.json)：2,210 项测试、三个任务物理重放、两环境完整流程、原生 batch64 及严格检查点迁移通过。属于功能回归，不是新的策略成功率或吞吐结果；正式残差训练仍暂停。

- [桌面三色目标方向路径采集（2026-11-01 完成）](table_buttons_target_relative_20261030/README.md)：近／中／远 × 红／黄／蓝，九组各 1,000 条全新成功示范，共 9,000 条、1,286,591 帧；包含逐组计数与精简审核摘要。这是脚本示范数据，不是模型成功率。
- [PAP 矩形区域评估（2026-10-23）](pap_rectangle_20261023/README.md)：修正四条绿色标签为矩形四边后，两组各 100 次，固定红色 **65%**、随机五色 **54%**；含位置图、逐次 CSV、完整计划及审计摘要。此前 88%/85% 使用了错误的小范围，不作为本矩形的结果。
- [PAP 平滑演示记录](pap_smoothing_demos_20261023.json)：固定红、蓝两种布局的功能演示，不是随机成功率评估。

以下为电梯任务的历史 RL 实验：

- [online_rl_20261009.json](online_rl_20261009.json)：8 个方法／配置的 120 次评估及逐按键成功率，包含 seed、gamma、scale、来源目录和原始 manifest／summary SHA-256。
- [online_rl_20261009.csv](online_rl_20261009.csv)：上表的紧凑版本。固定噪声后的 400k 残差实验额外使用之前已训练的 1M 噪声策略；不是相同总训练预算的比较。
- [smoothing_20261009.csv](smoothing_20261009.csv)：四轮平滑实验共 11 组、1,320 次评估，含同期基线、成功次数、实际运动 jerk 及任务时长。
- [smoothing_per_button_20261009.csv](smoothing_per_button_20261009.csv)：平滑实验的全部 132 行逐按键统计。

每组 120 次覆盖 12 个按键 × 中心／四角布局 × 2 次。所有评估均冻结参数。
初始噪声策略保留可复现的随机采样；不同执行和 seed 不保证相同轨迹。
原始 VLA 与 RL 训练曲线中的 recent SR、视频中的 12 个中心任务，均不替代这里的完整评估。
XYZ 的 119/120 是一个固定条件运行结果，不代表所有随机种子下均有 99.17% 成功率。

平滑表中的 jerk 和 duration ratio 来自双方共同成功的匹配任务。
每条轨迹在 120 Hz 物理时间上计算 RMS，再比较两组中位数；没有终止停帧或时间重采样。
`success_gate_pass` 是单组是否至少 119/120 且不低于同期基线，不等于已通过独立确认。
**没有滤波方案通过全部预设门槛，默认保持无新增后处理。**
