# 发布的实验结果摘要

这些文件从已完成的本地评估日志导出，不需要下载模型或运行 Isaac 即可查看。

- [online_rl_20261009.json](online_rl_20261009.json)：8 个方法／配置的 120 次评估及逐按键成功率，包含 seed、gamma、scale、来源目录和原始 manifest／summary SHA-256。
- [online_rl_20261009.csv](online_rl_20261009.csv)：上表的紧凑版本。固定噪声后的 400k 残差实验额外使用之前已训练的 1M 噪声策略；不是相同总训练预算的比较。
- [smoothing_20261009.csv](smoothing_20261009.csv)：四轮平滑实验共 11 组、1,320 次评估，含同期基线、成功次数、实际运动 jerk 及任务时长。
- [smoothing_per_button_20261009.csv](smoothing_per_button_20261009.csv)：平滑实验的全部 132 行逐按键统计。

每组 120 次覆盖 12 个按键 × 中心／四角布局 × 2 次。所有评估均冻结参数。
初始噪声策略保留可复现的随机采样；不同执行和 seed 不保证相同轨迹。
原始 VLA 与 RL 训练曲线中的 recent SR、视频中的 12 个中心任务，均不替代这里的完整评估。
XYZ 的 119/120 是一个固定条件运行结果，不代表所有随机种子下均有 99.17% 成功率。

平滑表中的 jerk 和 duration ratio 来自双方共同成功的匹配任务。
每条轨迹在 120 Hz 物理时间上计算 RMS，再比较两组中位数；没有终止停帧或时间重采样。
`success_gate_pass` 是单组是否至少 119/120 且不低于同期基线，不等于已通过独立确认。
**没有滤波方案通过全部预设门槛，默认保持无新增后处理。**

来源路径以仓库根为基准，原始 `outputs/` 未发布。详细复现及证据范围见
[固定噪声后的残差实验](../residual_on_frozen_noise.md)；精选视频及原文件哈希见
[媒体清单](../media/manifest.json)。
